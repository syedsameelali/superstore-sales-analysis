# Superstore Sales Analysis

Analysis of a retail Superstore dataset to identify profit/loss patterns 
across regions and categories using Excel and SQL (BigQuery).

## Key Finding
The Furniture category is unprofitable specifically in the Central region 
(-$2,871 profit), despite having the lowest sales volume of any region 
($163,797). The cause: Central's average discount on Furniture is 29.7%, 
nearly double every other region (12-15%). This points to a discounting 
policy issue rather than a demand problem.
